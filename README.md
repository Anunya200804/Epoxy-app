# ระบบบริหารจัดการงานติดตั้งพื้น Epoxy (Epoxy Floor Management System) 🏢✨

ระบบบริหารจัดการโครงการงานติดตั้งและเคลือบพื้น Epoxy ครบวงจร พัฒนาด้วยเทคโนโลยี **C# .NET 10** และ **Blazor Server** รองรับการจัดการตั้งแต่การประเมินราคา, ออกใบเสนอราคา, ติดตามขั้นตอนการปฏิบัติงาน 4 ขั้นตอน, แนบสลิปเงินมัดจำ/งวดสุดท้าย, ควบคุมสต็อกวัสดุ, จนถึงการออกรายงานและส่งออก PDF

---

## 🛠️ เทคโนโลยีและภาษาที่ใช้ (Tech Stack)

### 1. ภาษาที่ใช้ในการพัฒนา (Languages)
- **C# (C-Sharp 13 / .NET 10):** ภาษาหลักในการเขียนตรรกะทางธุรกิจ (Backend Business Logic, Services, Database Models)
- **Razor / HTML5:** ภาษาโครงสร้างเทมเพลตสำหรับแสดงผลหน้าจอ UI
- **CSS3 / Modern Responsive CSS:** การจัดวางเลย์เอาต์ (Flexbox, Grid), ธีมสี, แอนิเมชัน และการจัดรูปแบบสำหรับพิมพ์ (Print Stylesheet)
- **JavaScript (Vanilla JS):** ใช้สำหรับการดาวน์โหลดไฟล์และการสั่งพิมพ์เอกสารหน้าเว็บ (window.print())
- **SQL (MySQL / MariaDB):** ภาษาสำหรับจัดการฐานข้อมูลและการจัดเก็บข้อมูล

### 2. เฟรมเวิร์กและไลบรารี (Frameworks & Libraries)
- **ASP.NET Core Blazor Server (.NET 10):** ฟูลสแตกเว็บเฟรมเวิร์กแบบ Real-time SPA (Single Page Application) ผ่าน SignalR
- **Entity Framework Core 9 (EF Core):** ORM สำหรับติดต่อฐานข้อมูลเชิงวัตถุ
- **Pomelo.EntityFrameworkCore.MySql:** MySQL/MariaDB Database Provider สำหรับ EF Core
- **Bootstrap 5 & Lucide / FontAwesome Icons:** ไอคอนและชุดคอมโพเนนต์พื้นฐาน

### 3. ฐานข้อมูลและเครื่องมือ (Database & Tools)
- **MySQL / MariaDB (XAMPP):** ฐานข้อมูลสำหรับจัดเก็บข้อมูลทั้งหมด
- **Git & GitHub:** สำหรับการจัดการเวอร์ชันและเผยแพร่ซอร์สโค้ด

---

## ✨ ฟีเจอร์เด่นของระบบ (Features)

1. **แดชบอร์ดสรุปภาพรวม (Interactive Dashboard):**
   - Hero Banner ดีไซน์หรูหรา
   - การ์ดสถิติ (KPI Metrics) สรุปยอดโครงการ
   - ตารางโครงการล่าสุด และ แกลเลอรีภาพผลงาน (Carousel + Lightbox ซูมดูภาพ)
2. **ระบบจัดการลูกค้าและทีมช่าง (Customers & Technicians):**
   - บันทึกข้อมูลลูกค้า, หน้างาน, ข้อมูลทีมช่างผู้รับเหมา
3. **ระบบจัดการวัสดุและอุปกรณ์ (Inventory & Stock):**
   - คำนวณปริมาณการใช้วัสดุตามขนาดพื้นที่จริง ตารางเมตร
   - ระบบเบิก-จ่าย และรับเข้าวัสดุอัตโนมัติ
4. **ระบบใบเสนอราคา (Quotations):**
   - คำนวณราคา, ภาษีมูลค่าเพิ่ม (VAT 7%), เงินมัดจำ
   - แนบสลิปการโอนเงินมัดจำเพื่ออนุมัติโครงการ
5. **ระบบติดตามงานติดตั้ง 4 ขั้นตอน (Installation Tracking):**
   - ขั้นตอนที่ 1: เตรียมพื้นผิวและขัดพื้น
   - ขั้นตอนที่ 2: ทารองพื้นอีพ็อกซี่ (Primer)
   - ขั้นตอนที่ 3: ลงชั้นสีจริง (Base Coat)
   - ขั้นตอนที่ 4: เคลือบเงา Topcoat
   - แนบภาพถ่ายหน้างานจริงในแต่ละขั้นตอน
6. **ระบบการเงินและชำระเงินงวดสุดท้าย (Final Payment & Finance):**
   - แนบสลิปโอนเงินงวดสุดท้ายเพื่อปิดงาน
   - บันทึกรายรับ-รายจ่ายของโครงการ
7. **ระบบรายงานสรุปผลและพิมพ์เอกสาร (All-in-One Report & Export):**
   - รวบรวมใบเสนอราคา, สลิปมัดจำ, สลิปงวดสุดท้าย และภาพถ่าย 4 ขั้นตอน
   - ส่งออกและพิมพ์เป็นไฟล์ PDF ได้ทันที

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Installation Guide)

### สิ่งที่ต้องเตรียม (Prerequisites)
1. **.NET 10 SDK** (หรือ .NET 8/9/10)
2. **XAMPP** (เปิด Apache & MySQL) หรือ MySQL Server

### ขั้นตอนการรันระบบ
1. **เตรียมฐานข้อมูล:**
   - เปิด phpMyAdmin (http://localhost/phpmyadmin)
   - สร้างฐานข้อมูลชื่อ epoxy_floor_manager
   - Import ไฟล์ epoxy_floor_manager.sql
2. **รันโปรเจกต์:**
   `ash
   dotnet restore
   dotnet run
   `
3. **เปิดใช้งานบนเว็บเบราว์เซอร์:**
   - เข้าไปที่ http://localhost:5097
